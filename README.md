# Memory Studio (`hermes-memory-studio`)

Unified observability and interactive control plane for all four memory layers in Hermes Desktop:

1. **Built-in Memory (`MEMORY.md` & `USER.md`)** - Live character-budget gauges, usage percentages, and inline add/edit/delete for durable notes and user profile entries.
2. **Limbic (`limbic.db`)** - FSRS-4.5 power-law retention curve, trust gating, maturity/atrophy lifecycle badges, entity knowledge graph, and one-click Reinforce / Penalize / Decay Pass controls.
3. **Cass Memory (`~/.cass-memory/playbook.yaml`)** - Procedural playbook rules & anti-patterns with 90-day half-life confidence decay, 4x harmful penalty, maturity multipliers, helpful/harmful feedback buttons, and starter seeding.
4. **CASS Cross-Agent Session Search (`agent_search.db`)** - Full-text session search across agents and workspaces, plus one-click Hermes `state.db` session bridge export & re-indexing.

## Install in Hermes Desktop

Open **Capabilities -> Plugins -> Install** and paste:

```
https://github.com/hermesbaxterapp-bot/hermes-memory-studio
```
